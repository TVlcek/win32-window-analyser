# Win32 window analyser
A small primitive program/script that I wrote at 2 am in like an hour manually by hand 
for inspecting HWNDs when reverse engineering win32 based programs. Is written in C and has a dependency on win32 API (Mostly User32 lib)     
Can be extended to produce more information by calling more user32 functions for window handling and storing the results in the custom window info struct...
